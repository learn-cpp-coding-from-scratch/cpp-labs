# Задача 4

**Дано два возрастающих массива. Найти количество общих элементов в них.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/common_elements.hpp` | объявления функций — не изменяйте |
| `src/common_elements.cpp` | решение: тела функций |
| `src/common_elements_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/common_elements_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/common_elements_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-04-task-04_common-elements`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-04-task-04\."`, только ваши: `ctest --preset debug -R "lab-04-task-04\.student\."`.
