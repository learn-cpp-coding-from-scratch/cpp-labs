# Задача семинара 4

**Проверить, является ли массив 1 перестановкой элементов массива 2.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/permutation_of_array.hpp` | объявления функций — не изменяйте |
| `src/permutation_of_array.cpp` | решение: тела функций |
| `src/permutation_of_array_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/permutation_of_array_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/permutation_of_array_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-04-seminar-04_permutation-of-array`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-04-seminar-04\."`, только ваши: `ctest --preset debug -R "lab-04-seminar-04\.student\."`.
