# Задача 6

**Даны две матрицы размера n x k и k x m. Найти их произведение.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/matrix_product.hpp` | объявления функций — не изменяйте |
| `src/matrix_product.cpp` | решение: тела функций |
| `src/matrix_product_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/matrix_product_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/matrix_product_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-04-task-06_matrix-product`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-04-task-06\."`, только ваши: `ctest --preset debug -R "lab-04-task-06\.student\."`.
