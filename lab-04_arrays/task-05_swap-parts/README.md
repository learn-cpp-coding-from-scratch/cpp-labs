# Задача 5

**Дан массив из n + m элементов. Без использования вспомогательных массивов поменять в нём местами начало длины n и конец длины m.**

Пример:

a = [1, 2, 3, 4, 5, 6] , n = 2

Результат:

[3, 4, 5, 6, 1, 2]

Подсказка: Какая из реализованных ранее операций может вам помочь?
