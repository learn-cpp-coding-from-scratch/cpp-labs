# Задача 2

**Переставить элементы массива в обратном порядке без дополнительных массивов.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/reverse.hpp` | объявления функций — не изменяйте |
| `src/reverse.cpp` | решение: тела функций |
| `src/reverse_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/reverse_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/reverse_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-04-task-02_reverse`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-04-task-02\."`, только ваши: `ctest --preset debug -R "lab-04-task-02\.student\."`.
