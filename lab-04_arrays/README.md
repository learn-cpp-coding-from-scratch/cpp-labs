# Лабораторная работа 04. Функции. Циклические алгоритмы. Коллекции vector, array

*for, while, do-while, range based for loop, std::vector, std::array*

Рассмотрите теоретический материал по работе с `std::vector` и `std::array`: https://en.cppreference.com/w/cpp/container/vector, https://en.cppreference.com/w/cpp/container/array

**Указание.** Для работы с массивами рекомендуется использовать контейнеры `std::array` или `std::vector`. Для двумерных массивов рекомендуется использовать `std::vector<std::vector<int>>`.

**Задание:** Разработайте приложения для решения следующих задач, реализуя основную бизнес-логику в функциях. Функции и их параметры заданы в файлах `include/*.hpp` каждой задачи, ввод данных и вывод результата в `main` напишите сами.

Задачи разбираем на занятии; что не успели — доделайте дома.

| 3 | Дан массив (array) из n чисел. Не используя вспомогательный массив поменять местами элементы таким образом, чтобы сначала шли отрицательные элементы, затем нулевые, потом положительные элементы. Взаимное расположение элементов в своих категориях должно остаться неизменным. | [seminar-03_sign-order](seminar-03_sign-order/README.md) |
| 4 | Проверить, является ли массив 1 перестановкой элементов массива 2. | [seminar-04_permutation-of-array](seminar-04_permutation-of-array/README.md) |
| 5 | Выполните транспонирование массива размерности n x m (полученная из исходной матрицы заменой строк на столбцы). | [seminar-05_transpose](seminar-05_transpose/README.md) |
