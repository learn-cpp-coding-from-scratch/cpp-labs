# Задача семинара 3

**Дан массив (array) из n чисел. Не используя вспомогательный массив поменять местами элементы таким образом, чтобы сначала шли отрицательные элементы, затем нулевые, потом положительные элементы. Взаимное расположение элементов в своих категориях должно остаться неизменным.**

Размер `std::array` задаётся при компиляции, поэтому n — константа `ARRAY_SIZE` из заголовка задачи.

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/sign_order.hpp` | объявления функций — не изменяйте |
| `src/sign_order.cpp` | решение: тела функций |
| `src/sign_order_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/sign_order_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/sign_order_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-04-seminar-03_sign-order`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-04-seminar-03\."`, только ваши: `ctest --preset debug -R "lab-04-seminar-03\.student\."`.
