# Задача 3

**Дан массив из n целых чисел. Проверить, является ли он перестановкой, то есть содержит различные числа от 1 до n.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/one_to_n_permutation.hpp` | объявления функций — не изменяйте |
| `src/one_to_n_permutation.cpp` | решение: тела функций |
| `src/one_to_n_permutation_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/one_to_n_permutation_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/one_to_n_permutation_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-04-task-03_one-to-n-permutation`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-04-task-03\."`, только ваши: `ctest --preset debug -R "lab-04-task-03\.student\."`.
