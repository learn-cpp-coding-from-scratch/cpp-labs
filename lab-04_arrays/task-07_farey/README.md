# Задача 7

**Последовательностью Фарея. Напечатать в порядке возрастания все простые несократимые дроби, заключенные между 0 и 1, знаменатели которых меньше заданного числа n.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/farey.hpp` | объявления функций — не изменяйте |
| `src/farey.cpp` | решение: тела функций |
| `src/farey_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/farey_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/farey_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-04-task-07_farey`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-04-task-07\."`, только ваши: `ctest --preset debug -R "lab-04-task-07\.student\."`.
