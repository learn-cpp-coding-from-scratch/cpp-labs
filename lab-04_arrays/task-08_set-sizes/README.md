# Задача 8

**Дано целое число k, а также k наборов ненулевых целых чисел. Признаком завершения каждого набора является число 0 (оно в набор не входит). Для каждого набора вывести количество его элементов. Вывести также общее количество элементов во всех наборах.**

| `tests/open/set_sizes_test.cpp` | открытые тесты — не изменяйте |
