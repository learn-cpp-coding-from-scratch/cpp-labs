# Задача 2

**Напишите сравнение комплексных чисел на равенство так, как это делалось до C++20: задача собирается с флагом `-std=c++17`.**

Цель — увидеть, сколько кода для этого нужно и какие у него ограничения. Задача выполняется после части 1 задачи о классе `ComplexNumber`; в этой задаче — своя, урезанная копия класса: конструктор и функции доступа. Стандарт C++17 для всех целей задачи задаёт её `CMakeLists.txt` (`CXX_STANDARD 17`); открытый тест `LanguageStandardIsCpp17` проверяет, что это так.

1. **Эксперимент (в решение не входит).** Временно объявите `==` и `!=` функциями-членами класса и проверьте, какие строки `main` компилируются:

   ```cpp
   std::cout << (z == 1.0) << '\n';
   std::cout << (z != 1.0) << '\n';
   std::cout << (1.0 == z) << '\n';
   std::cout << (1.0 != z) << '\n';
   ```

   Запишите сообщение компилятора для строк, которые не компилируются, и объясните его.

2. **Решение.** Реализуйте `==` и `!=` обычными функциями (не членами класса) с одной сигнатурой `(const ComplexNumber&, const ComplexNumber&)` — они объявлены в `complex_number.hpp`. Проверьте, что компилируются все четыре строки.

3. Другой способ — отдельные перегрузки `(const ComplexNumber&, double)` и `(double, const ComplexNumber&)` для каждой операции. Сколько функций сравнения понадобилось бы в этом способе и сколько — в пункте 2?
