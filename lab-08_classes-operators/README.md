# Лабораторная работа 08. Классы. Перегрузка операций. Исключения

*Класс, инвариант, конструктор, константные функции доступа, перегрузка операций, сравнение `==` и `<=>` (C++20), правило нуля, исключения, тесты*

**Указание.**

1. Многофайловый проект: каждый класс — в паре файлов, объявление — в заголовочном файле `include/*.hpp`, реализация функций-членов и функций-операций — в `src/*.cpp`.
2. Поля классов — закрытые (`private`), с суффиксом `_` (`numerator_`). Функции-члены, которые не меняют объект, объявляйте константными, а если они возвращают значение — с атрибутом `[[nodiscard]]`.
3. Ввод и вывод — только в классе `Program`: классы данных с клавиатурой и консолью не работают (кроме операции `<<`), поэтому их можно проверять тестами.
4. Ошибки (нулевой знаменатель, деление на ноль) обрабатывайте с помощью исключений.
5. Для всех функций разработайте unit-тесты (Google Test: https://google.github.io/googletest/primer.html).

**Литература:**

1. Перегрузка операторов: https://cppreference.com/cpp/language/operators
2. Сравнения по умолчанию и `<=>`: https://cppreference.com/cpp/language/default_comparisons

**Задание:** Разработайте классы для решения следующих задач. Функции и их параметры заданы в файлах `include/*.hpp` каждой задачи, ввод данных и вывод результата в `main` напишите сами.
