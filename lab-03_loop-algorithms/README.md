# Лабораторная работа 03. Циклические алгоритмы

*while, do-while, for, break, continue*

Ознакомьтесь с операторами цикла в языке C++: https://en.cppreference.com/w/cpp/language/statements#Iteration_statements

Задачи семинара сначала решите, просто выводя результат на экран, потом — сохраняя его в коллекцию: функции задач возвращают результат (число, строку или `std::vector`), а выводит его `main`.

**Задание:** Разработайте приложения для решения следующих задач. Функции и их параметры заданы в файлах `include/*.hpp` каждой задачи, ввод данных и вывод результата в `main` напишите сами.
