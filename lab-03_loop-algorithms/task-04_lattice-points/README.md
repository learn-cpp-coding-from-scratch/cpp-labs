# Задача 4

**Количество точек решетки.** Для заданного _n_ найдите количество целых неотрицательных пар _x_ и _y_ таких, что $x^2 + y^2 < n^2$, пользуясь только операциями с целыми числами.

Вы получите дополнительные баллы, если ваше решение совершает линейное от _n_ количество операций. То есть существует такая константа $C$, что количество операций не превосходит $Cn$ для любого $n$.
