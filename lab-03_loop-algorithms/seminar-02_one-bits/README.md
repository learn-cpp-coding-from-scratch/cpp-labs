# Задача семинара 2

**Вычислить количество единичных бит числа.** Число имеет тип `int` и может быть отрицательным: отрицательное число хранится в дополнительном коде, и считаются единицы в этой записи, включая знаковый бит (например, для `-1` все биты `int` — единицы).

**Запрещено** переводить число в беззнаковый тип каким-либо способом: `static_cast<unsigned int>`, приведение в стиле C `(unsigned)number`, присваивание переменной типа `unsigned`, `std::bit_cast`. Нельзя также пользоваться `std::popcount` и `std::bitset`. Работайте с самим значением типа `int`.
