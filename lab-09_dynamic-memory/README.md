# Лабораторная работа 09. Динамическое выделение памяти. Перегрузка операций. Исключения

*Класс, владеющий динамической памятью, правило пяти, идиома копирования и обмена, шаблон класса, перегрузка операций, `<=>` (C++20), исключения, тесты*

**Указание.**

1. Многофайловый проект. Шаблон класса целиком — в заголовочном файле `include/*.hpp`: компилятору нужно определение шаблона в каждой единице трансляции, где создаётся `Array<int>`, `Matrix<double>` и т. д. В файле сначала класс с объявлениями функций-членов, ниже — их определения вне класса; функции-операции — скрытые друзья, они определяются внутри класса. Обычные (не шаблонные) функции — в `src/*.cpp`.
2. Поля классов — закрытые (`private`), с суффиксом `_` (`size_`). Функции-члены, которые не меняют объект, объявляйте константными.
3. Ввод и вывод с консолью — только в `*_main.cpp`: классы работают с потоками только в операциях `<<` и `>>`, поэтому их можно проверять тестами.
4. Ошибки (разные размеры, деление на ноль, индекс за границей) обрабатывайте с помощью исключений.
5. Для всех функций разработайте unit-тесты (Google Test: https://google.github.io/googletest/primer.html).

**Литература:**

1. Правило трёх, пяти и нуля: https://cppreference.com/cpp/language/rule_of_three
2. Перегрузка операторов: https://cppreference.com/cpp/language/operators
3. Шаблоны классов: https://cppreference.com/cpp/language/class_template

**Задание:** Разработайте шаблоны классов для решения следующих задач. Функции и их параметры заданы в файлах `include/*.hpp` каждой задачи, ввод данных и вывод результата в `main` напишите сами.
