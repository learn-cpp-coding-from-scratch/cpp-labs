# Задача семинара 1

**Разработайте шаблон класса `Array<T>` — массив фиксированного размера в динамической памяти — с правилом пяти, операциями над массивами, вводом и выводом, и класс `ArrayService` с функциями обработки массива.**

Объявления даны в `include/array.hpp` и `include/array_service.hpp`: в комментариях к ним — что делает каждая функция и примеры. Определения функций пишите в тех же файлах ниже классов, операции-друзья — внутри класса. После каждого пункта проверяйте себя открытыми тестами и дописывайте свои тесты в `tests/student/`.

Образец — класс `Array` из примера DemoArray (https://github.com/avelana/cpp-examples/tree/master/07-structures-classes/DemoArray), в котором `double` заменён на `T`.

### 1. Поля и правило пяти

1. Поля: `size_` (тип `std::size_t`) и `data_` (тип `T*`). Инвариант: `data_` указывает на блок из `size_` элементов; у пустого массива `size_ == 0` и `data_ == nullptr`.
2. Конструкторы:
   - `explicit Array(std::size_t size = 0)` — `size` элементов, равных `T{}`;
   - `Array(std::size_t size, const T& value)` — `size` элементов, равных `value`;
   - `Array(std::initializer_list<T> values)` — `Array<int> a{1, 2, 3}`.
3. Правило пяти: деструктор, конструктор копирования (глубокое копирование), конструктор перемещения (`noexcept`, исходный массив становится пустым) и присваивание. Присваивание копированием и перемещением — одна операция `operator=(Array other) noexcept` по идиоме копирования и обмена: параметр передаётся по значению и создаётся копированием или перемещением аргумента, а скрытый друг `swap` обменивает поля `*this` и параметра.

### 2. Доступ к элементам

1. `size()` и `operator[]` (без проверки индекса) уже написаны.
2. `at(index)` — доступ с проверкой: при `index >= size()` исключение `std::out_of_range`.

### 3. Операции

Составные операции — функции-члены, возвращают ссылку на `*this`; бинарные — скрытые друзья, выраженные через составные.

| Операция | Что делает |
|---|---|
| `a = value` | присваивает `value` всем элементам |
| `a += b`, `a -= b`, `a + b`, `a - b` | поэлементные сложение и вычитание массивов; при разных размерах — исключение `std::invalid_argument` |
| `a += x`, `a -= x`, `a + x`, `x + a`, `a - x` | поэлементные сложение и вычитание массива и значения `x` типа `T` |
| `a *= x`, `a * x`, `x * a` | поэлементное умножение на `x` |
| `a /= x`, `a / x` | поэлементное деление на `x`; при `x == T{}` — исключение `std::domain_error` |
| `++a`, `a++`, `--a`, `a--` | увеличение (уменьшение) каждого элемента на 1; префиксные возвращают ссылку на массив, постфиксные — копию прежнего значения |
| `a == b` | массивы равны, если равны размеры и все элементы |
| `a == x` | все элементы равны `x` (у пустого массива — `true`) |
| `a <=> b` | лексикографическое сравнение: решает первый различающийся элемент (с меньшим индексом); если один массив — начало другого, меньше более короткий |

Операции `!=`, `<`, `>`, `<=`, `>=` вручную не пишите — компилятор получает их из `==` и `<=>`.

### 4. Ввод и вывод

1. `out << a` выводит элементы через запятую с пробелом в квадратных скобках: `[1, 2, 3]`, пустой массив — `[]`.
2. `in >> a` читает размер, затем элементы: `3 1 2 3`. При ошибке ввода (не число, отрицательный размер, элементов меньше, чем размер) поток переходит в состояние ошибки (`failbit`), а массив не меняется.

### 5. Класс ArrayService

Статические шаблоны функций-членов для массива `Array<T>` (тип `T` выводится из аргумента: `ArrayService::sum(a)`):
- `sum(a)` — сумма элементов (у пустого массива — `T{}`);
- `average(a)` — среднее арифметическое типа `double`;
- `findMin(a)`, `findMax(a)` — наименьший и наибольший элементы;
- `findIndexMin(a)`, `findIndexMax(a)` — индекс первого наименьшего (наибольшего) элемента.

Для пустого массива `average`, `findMin`, `findMax`, `findIndexMin`, `findIndexMax` бросают исключение `std::invalid_argument`.

### 6. Тесты

Примеры, которые проверяют открытые тесты:

| Выражение | Ожидаемый результат |
|---|---|
| `Array<int>(3)` | `[0, 0, 0]` |
| `Array<int>{3}` | `[3]` — один элемент |
| `Array<int>{1, 2} + Array<int>{1}` | исключение `std::invalid_argument` |
| `2 * Array<int>{1, 2}` | `[2, 4]` |
| `Array<int>{1, 2} / 0` | исключение `std::domain_error` |
| `Array<int>{1, 2} < Array<int>{1, 2, 0}` | `true` |
| `Array<int>{2} > Array<int>{1, 9}` | `true` |
| `ArrayService::findIndexMax(Array<int>{3, 7, 7})` | `1` |

Проверьте своими тестами правило пяти: после `Array<int> b = a; b[0] = 9;` массив `a` не изменился; после `Array<int> c = std::move(a);` массив `a` пуст; самоприсваивание `a = a;` не портит массив.

### 7. Вопросы

1. Чем отличаются `Array<int>(3)` и `Array<int>{3}`? Почему так же ведёт себя `std::vector<int>`?
2. Зачем конструктор `Array(std::size_t)` объявлен `explicit`? Что начало бы компилироваться без `explicit`? Почему `a = 5` и тогда присваивало бы 5 всем элементам, а не создавало массив из пяти элементов?
3. Почему `operator[]` не проверяет индекс, а `at` проверяет? Как сделано в `std::vector`?
4. Почему одна операция `operator=(Array other)` заменяет присваивание и копированием, и перемещением? Почему она даёт строгую гарантию безопасности исключений и не нуждается в проверке самоприсваивания?
5. Почему бинарные операции шаблона — скрытые друзья, а не отдельные шаблоны функций `template <typename T> Array<T> operator+(...)`? Какое выражение тогда перестало бы компилироваться?
6. Какой тип результата у `a <=> b` для `Array<int>` и для `Array<double>` и почему?
7. Почему определения функций-членов шаблона нельзя перенести в `.cpp`?
