# Задача семинара 2

**Во входном файле строки из маленьких латинских букв, вывести количество различных строк.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/distinct_strings.hpp` | объявления функций — не изменяйте |
| `src/distinct_strings.cpp` | решение: тела функций |
| `src/distinct_strings_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/distinct_strings_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/distinct_strings_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-05-seminar-02_distinct-strings`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-05-seminar-02\."`, только ваши: `ctest --preset debug -R "lab-05-seminar-02\.student\."`.
