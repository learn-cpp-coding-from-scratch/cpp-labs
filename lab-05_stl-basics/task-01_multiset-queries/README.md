# Задача 1

**Данo 2 файла, один с исходными данными (числа, M штук), второй файл с N запросами (каждый запрос в отдельной строке): add number (например, add 7) - добавить число, delete number - удалить число, find_min - вывести минимум, is_exist number - проверить принадлежность коллекции. Загрузить исходные данные в коллекцию и выполнить над элементами все запросы из второго файла. Результат выполнения записать в выходной файл. (std::multiset)**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/multiset_queries.hpp` | объявления функций — не изменяйте |
| `src/multiset_queries.cpp` | решение: тела функций |
| `src/multiset_queries_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/multiset_queries_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/multiset_queries_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-05-task-01_multiset-queries`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-05-task-01\."`, только ваши: `ctest --preset debug -R "lab-05-task-01\.student\."`.
