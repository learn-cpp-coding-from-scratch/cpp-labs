# Задача 2

**Есть N задач, каждая выполняется раз в a[i] секунд . На секунде 0 выполнились все задачи (то есть первая будет в 0, a[1], 2*a[1] ...). Вывести K первых выполнений. Если две задачи в одну и ту же секунду выполняются, то первой вывести с меньшим номером. (std:pair<int, int>)**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/periodic_tasks.hpp` | объявления функций — не изменяйте |
| `src/periodic_tasks.cpp` | решение: тела функций |
| `src/periodic_tasks_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/periodic_tasks_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/periodic_tasks_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-05-task-02_periodic-tasks`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-05-task-02\."`, только ваши: `ctest --preset debug -R "lab-05-task-02\.student\."`.
