# Лабораторная работа 05. Базовые элементы STL

*std::string, std::set, std::multiset, std::pair, std::map, std::multimap, auto, range-based for loop, алгоритмы: sort, find, count, for_each*

**Указание.**

1. Для работы с массивами рекомендуется использовать контейнеры std.
2. Для работы с файлами познакомьтесь с материалами: https://edufpmi.bsu.by/mod/resource/view.php?id=949, https://metanit.com/cpp/tutorial/8.1.php
3. Ввод и вывод исходных данных оформляйте с помощью функций. Размещайте эти функции в отдельных файлах.
4. Для всех функций разработайте unit-тесты. Познакомьтесь с документацией Google Test: https://google.github.io/googletest/primer.html, образцы тестов: https://google.github.io/googletest/samples.html. При разработке тестов используйте разнообразные `ASSERT_*` / `EXPECT_*`.

Задачи, которые читают файлы, спрашивают путь к файлу; примеры файлов лежат в папке `data/` задачи. Относительный путь (`data/strings.txt`) отсчитывается от текущей папки, в которой запущена программа, — запускайте программу из папки задачи или вводите полный путь.

**Чтение и запись в файл — пример кода:**

```cpp
#include <fstream>
#include <iostream>
#include <string>

int main()
{
    // Папка data должна существовать в текущей папке
    std::ofstream output("data/dataOut.txt", std::ios::app); // app — дописывать в конец файла
    const int count = 10;
    for (int i = 0; i < count; ++i) {
        output << i + 1 << ' ';
    }
    output.close();

    std::ifstream input("data/data.txt");
    std::string line;
    while (std::getline(input, line)) {
        std::cout << line << '\n';
    }
    return 0;
}
```

**Задание:** Разработайте приложения для решения следующих задач. Функции и их параметры заданы в файлах `include/*.hpp` каждой задачи, ввод данных и вывод результата в `main` напишите сами.
