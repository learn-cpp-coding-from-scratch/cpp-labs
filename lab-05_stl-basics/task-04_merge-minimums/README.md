# Задача 4

**Даны N чисел. N - 1 раз делают следующее - берут два минимальных числа, выкидывают их из массива и добавляют их сумму. На каждом шаге алгоритма выводите минимум и максимум в массиве.**

## Файлы задачи

| Файл | Что в нём |
|---|---|
| `include/merge_minimums.hpp` | объявления функций — не изменяйте |
| `src/merge_minimums.cpp` | решение: тела функций |
| `src/merge_minimums_main.cpp` | программа: ввод данных, вызов функций, вывод |
| `tests/open/merge_minimums_test.cpp` | открытые тесты — не изменяйте |
| `tests/student/merge_minimums_test.cpp` | ваши тесты: добавляйте сюда |

Программа собирается в цель `lab-05-task-04_merge-minimums`. Тесты задачи (открытые и ваши): `ctest --preset debug -R "lab-05-task-04\."`, только ваши: `ctest --preset debug -R "lab-05-task-04\.student\."`.
