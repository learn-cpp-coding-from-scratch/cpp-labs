# Задача семинара 5

**Даны два целых числа: D (день) и М (месяц), определяющие правильную дату невисокосного года.** Вывести значения D и М для даты, предшествующей указанной.

*Выполнить задание с использованием конструкции выбора switch.*

*Источник: Абрамян М. Э. 1000 задач по программированию. Ч. I, 2004, Case8.*
