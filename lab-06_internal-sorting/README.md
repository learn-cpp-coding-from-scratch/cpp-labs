# Лабораторная работа 06. Внутренние сортировки

*for, while, do-while, range based for loop, chrono*

**Указание.**

1. Алгоритмы сортировки, операцию обмена элементов, ввод и вывод массива оформите в виде отдельных функций. Размещайте эти функции в отдельных файлах с заголовочными файлами.
2. Для хранения данных используйте `std::vector`.
3. Время работы алгоритмов измеряйте в конфигурации Release, а не Debug: в Debug оптимизация отключена, и это сильно искажает результаты. Сборка и запуск: `cmake --preset release && cmake --build --preset release`, программа задачи — в папке `build/release/bin/<задача>/` (например, `lab-06-task-01`), рядом с ней — её папка `data/`.
4. Изучите код примеров: https://github.com/avelana/cpp-examples/tree/master/04-functions/DemoChrono, https://github.com/avelana/cpp-examples/tree/master/04-functions/HomeWork/BubbleSortWithTemplate
5. Разработайте unit-тесты для алгоритмов сортировки (Google Test: https://google.github.io/googletest/primer.html).

**Литература:**

1. Кнут Д. Э. Искусство программирования. Том 3. Сортировка и поиск. — 2-е изд. — М.: Вильямс, 2007. — 832 с.
2. Седжвик Р. Фундаментальные алгоритмы на C++. Анализ/Структуры данных/Сортировка/Поиск. — К.: ДиаСофт, 2001. — 688 с.
3. Идеи алгоритмов сортировки массивов: https://habr.com/post/204600/, https://habr.com/ru/post/422085/, https://habr.com/ru/post/415935/, https://habr.com/ru/post/414653/
4. Страуструп Б. Программирование: принципы и практика с использованием C++, 2-е изд. — М.: Вильямс, 2016. — 1328 с. (библиотека chrono — с. 1102).
5. Функции для работы с датой и временем: https://ru.cppreference.com/w/cpp/chrono
6. Основные концепции библиотеки chrono: https://habr.com/ru/post/324984/

**Задание:** Разработайте приложение для решения следующей задачи. Функции и их параметры заданы в файлах `include/*.hpp` каждой задачи, ввод данных и вывод результата в `main` напишите сами.
