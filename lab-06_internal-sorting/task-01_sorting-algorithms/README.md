# Задача 1

**Дан массив чисел a[n], n > 0. Реализуйте десять алгоритмов сортировки массива по возрастанию, подсчитайте для каждого число сравнений и обменов элементов, измерьте время работы и проведите экспериментальное сравнение алгоритмов.**

### 1. Алгоритмы внутренней сортировки

Функции сортировки — шаблоны: сортируют `std::vector<int>` и `std::vector<double>`.

| № | Сортировка | Функция | Идея |
|---|---|---|---|
| 1 | вставками | `insertionSort` | см. лекции |
| 2 | Шелла | `shellSort` | сортировка вставками с предварительными «грубыми» проходами: сравниваются элементы, стоящие на расстоянии d друг от друга, затем d уменьшается до 1 |
| 3 | пузырьком | `bubbleSort` | см. лекции |
| 4 | чётно-нечётная | `oddEvenSort` | проход «нечёт-чёт»: 1-й элемент сравнивается со 2-м, 3-й с 4-м и так далее; затем проход «чёт-нечёт»: 2-й с 3-м, 4-й с 5-м…; проходы чередуются, пока после двух проходов подряд не произошло ни одного обмена |
| 5 | шейкерная | `cocktailSort` | см. лекции |
| 6 | расчёской | `combSort` | улучшенная пузырьковая: сначала сравниваются элементы на большом расстоянии, расстояние уменьшается до 1 |
| 7 | выбором | `selectionSort` | см. лекции |
| 8 | двусторонним выбором | `doubleSelectionSort` | за проход по неотсортированной части находятся минимум и максимум: минимум ставится на первое место, максимум — на последнее |
| 9 | быстрая | `quickSort` | см. лекции |
| 10 | слиянием | `mergeSort` | см. лекции |

Тесты одной сортировки запускайте по имени функции: `ctest --preset debug -R bubbleSort`.

### 2. Сравнительный анализ

Каждая функция сортировки возвращает число сравнений и число обменов (перемещений) элементов — структуру `SortStatistics`. Время работы алгоритма измерьте с помощью библиотеки `chrono`.

*Зам. С помощью chrono не вывести дату и время в читаемом виде: используйте `std::time_t` и `std::ctime` или библиотеку date.h (https://howardhinnant.github.io/date/date.html).*

### 3. Эксперимент

1. Функции заполнения массива тестовыми данными разместите в файле `data_generation.cpp`. Сгенерированные данные запишите в файлы, имя которых определяется размером и порядком данных: `input_10_int_random_1.txt`, `input_1000_int_ascending.txt`. Всего 20 файлов; автоматизируйте их создание.
2. Сравните алгоритмы **на одних и тех же входных данных** для n = 10, 100, 1 000, 10 000 и порядка элементов: по возрастанию, по убыванию, случайный (3 разных случайных набора).
3. Результат каждой сортировки запишите в выходной файл.
4. Результаты эксперимента оформите на основе нескольких запусков в виде сводной таблицы по образцу `06-Lab-Результаты эксперимента.xlsx`: для каждого набора данных, каждого алгоритма и каждого n — число сравнений, число обменов и время (мс), последний блок — средние значения по случайным наборам.

### Файлы эксперимента

Программа собирается в отдельную папку `build/<пресет>/bin/<задача>/`, и при сборке туда же копируется папка `data/` задачи. Папку с данными программа находит рядом с собой — функцией `cpplabs::dataDirectory()` из `<cpplabs/paths.hpp>`, поэтому её можно запускать из любой текущей папки и переносить вместе с папкой `data/`.

Файлы эксперимента программа записывает в `data/` рядом с собой: входные — в `data/input/`, отсортированные — в `data/output/`, сводную таблицу — в `data/results.csv`. Сгенерированные файлы в git не добавляются (`data/.gitignore`): программа создаёт их заново при каждом запуске.
