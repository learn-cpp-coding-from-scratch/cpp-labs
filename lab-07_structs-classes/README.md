# Лабораторная работа 07. Структуры и классы

*struct, class, enum class, поля и функции-члены, конструкторы, константные функции-члены, перегрузка operator<<, std::map, чтение из файла, запись в файл*

**Указание.**

1. Каждую структуру и каждый класс размещайте в отдельной паре файлов: объявление — в заголовочном файле `include/*.hpp`, реализацию функций-членов — в `src/*.cpp`.
2. Поля структур — открытые, без суффикса (`name`). Поля классов — закрытые (`private`), с суффиксом `_` (`code_`); значения им задаёт конструктор, читаются они константными функциями-членами `get…()`.
3. Функции-члены, которые не меняют объект, объявляйте константными (`toString() const`), а если они возвращают значение — с атрибутом `[[nodiscard]]`: компилятор предупредит, если результат не использован. Строки, коллекции и объекты передавайте в функции по константной ссылке.
4. Работа с файлами: https://metanit.com/cpp/tutorial/8.1.php, https://ru.cppreference.com/w/cpp/io/basic_ifstream
5. Для всех функций разработайте unit-тесты (Google Test: https://google.github.io/googletest/primer.html).

**Литература:**

1. Страуструп Б. Программирование: принципы и практика с использованием C++, 2-е изд. — М.: Вильямс, 2016. — 1328 с. (глава 9 — классы, глава 10 — потоки ввода и вывода, файлы).
2. Классы: https://ru.cppreference.com/w/cpp/language/classes
3. Перечисления, enum class: https://ru.cppreference.com/w/cpp/language/enum
4. Перегрузка операторов: https://ru.cppreference.com/w/cpp/language/operators

**Задание:** Разработайте приложение для решения следующей задачи. Функции и их параметры заданы в файлах `include/*.hpp` каждой задачи, ввод данных и вывод результата в `main` напишите сами.
